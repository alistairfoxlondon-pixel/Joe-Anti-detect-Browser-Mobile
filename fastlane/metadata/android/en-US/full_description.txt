Joe Browser gives every browser profile its own isolated identity on your Android device — its own cookies, storage, proxy and fingerprint — so you can manage multiple accounts side by side without them bleeding into each other. Everything stays on your phone. There is no account, no sync service and no telemetry.

WHAT EACH PROFILE GETS
• Isolated web storage — per-profile cookie jar and site data (AndroidX WebKit MULTI_PROFILE where supported)
• A unique, internally consistent fingerprint — OS, screen and DPR, WebGL vendor/renderer, CPU cores, memory, touch points, timezone and locale always agree with each other
• Canvas, audio and hardware noise injected at document start
• Its own proxy: HTTP, HTTPS and SOCKS5, including username/password authentication via an on-device CONNECT relay

PROXY LIBRARY
• Paste a whole proxy list and Joe Browser parses it, checks every endpoint (exit IP, latency, country) and keeps it healthy
• Watch any proxy: get notified the moment it drops offline, recovers, or its exit IP rotates
• System WebView can't carry proxy credentials, so Joe Browser bridges them through a local relay — the exact path its checker uses, so what you test is what you get

EVERYDAY TOOLS
• Paste as Human: types clipboard text with human timing into any field
• Built-in tracker counter: the toolbar shows how many requests each page fires and how many reach known tracker hosts, and taps through to the full per-host list
• History with search, per-profile filters and soft-delete trash; JSON backup export and restore (with or without passwords)
• One-tap fingerprint checks that open BrowserScan, IPHey, PixelScan, IPFighter or Whoer inside the profile, so the site sees the profile's identity and not your device
• Engines tab to see which identity families and browser builds each profile can use, and Tools tab for every setting in one place

PRIVATE BY DESIGN
• All data local to the device; backups and device transfer excluded by default
• Proxy passwords encrypted at rest with the Android Keystore (AES-256-GCM); a full backup writes them in plain text inside the file, so the app offers a no-passwords export too
• No ads, no analytics, no account required

HONEST LIMITATIONS
Joe Browser is not an anonymity cloak. Sites can still correlate accounts by IP address, logins and behavior. Firefox identities are UA-level only (rendering is the system WebView). Some very old WebViews share storage between profiles and the app says so on screen when that happens. Android WebViews cannot execute browser extensions, so Joe Browser does not pretend to install them: everything a page receives comes from the fingerprint layer or the page itself.

For power users managing multiple client accounts, social profiles, QA personas and scraping identities — without renting a cloud anti-detect subscription.
